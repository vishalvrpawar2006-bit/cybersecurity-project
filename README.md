# Cybersecurity Project: Password Strength Analyzer & Security Audit Tool

## Overview
This project is an easy-to-build, beginner-friendly Python tool designed to evaluate password strength against common cryptographic attacks and run a basic local port scan vulnerability assessment.

## Features
- **Password Complexity & Entropy Analyzer**: Evaluates character variety and calculates Shannon entropy.
- **Basic Network/Port Scanner**: Scans specified local ports to identify open services.
- **Interactive Jupyter Notebook**: Fully documented code and explanations for learning security concepts.

## Installation & Setup
1. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the Jupyter Notebook:
   ```bash
   jupyter notebook cybersecurity_project.ipynb
   ```
